# Restauración interactiva de señales de audio degradadas

TFG — Ingeniería de Telecomunicaciones (ETSIT/UPV).

App de demostración con modelos preentrenados de restauración de audio:
denoising (DeepFilterNet3), dereverberation (MP-SENet), super-resolución
(AudioSR), de-clipping (VoiceFixer v2), separación de fuentes (HTDemucs v4)
y un modelo combinado multi-tarea (ClearVoice/MossFormer2).
